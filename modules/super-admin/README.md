# Super Admin Module

This directory represents the administrative control panel for the Old Age Home Management System.

## Structure
- /dashboard: Analytics summary, logs preview
- /users: Add/edit/delete administration panel users
- /roles: Access control management and permissions matrices
- /reports: Print-ready auditing, donation sheets, and resident directories
- /statistics: Demographics and donation metrics rendered dynamically
- /assets: Cohesive theme files (style.css and main.js) with responsive layouts and modern glassmorphic overlays.

## Running the module
Ensure Apache and PHP are running locally, and navigate to:
[http://localhost/Old-Age-Home-Management-System/modules/super-admin/dashboard/index.php](http://localhost/Old-Age-Home-Management-System/modules/super-admin/dashboard/index.php)
